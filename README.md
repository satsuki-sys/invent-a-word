# Invent a Word We Need

An entry for the [make.fun](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0) competition **Invent a Word We Need**.

## The entry

> **Flakeglee (n.) — the secret delight when a plan falls through and your evening suddenly becomes yours again.**

One invented English word, defined in a single clear line.

## How it works

`main.py` writes the entry text to `/output/entry.txt`. The entry is 108 characters, a single line, within the competition's 1–140 character gate.

```sh
python3 main.py
```
